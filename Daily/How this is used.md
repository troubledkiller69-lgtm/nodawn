# Daily

Back to [[No Dawn - Home]] · Live work: [[Open Items]]

`Daily/` is a scratchpad, not a record. One note per day, created from `Templates/Daily Note`.

The rule that keeps the vault clean: **a daily note never holds a decision.** Everything worth keeping is triaged out into its real home before the day closes.

| Goes to | For |
|---|---|
| `Brainstorm/Idea - <name>.md` | A new idea, `status: raw` |
| [[Open Items]] | Work to actually do |
| [[Realism Ledger]] | A ruling and its numbers |
| [[Lessons]] | A Studio or MCP gotcha |
| `Spec/` | Something that settles a question |
| `Build/Hub - Build History.md` | A build pass that happened |

Daily notes are not referenced from the home page and are not part of the graph's working set. They expire.
